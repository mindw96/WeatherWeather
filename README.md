# 쌓임쌓임 (Window Weather)

macOS의 창 위에 눈·비·낙엽·벚꽃·비눗방울·색종이·반딧불·별가루를 표시하는 작은 앱입니다. 창의 윗변에 효과가 내려앉고, 창과 바람에 반응합니다. Dock과 메뉴 막대에서 설정을 열 수 있습니다. 회원가입·로그인 없이 사용하며 수동 효과는 인터넷 없이 동작합니다. 선택형 실제 날씨 연동과 업데이트 확인·다운로드에는 인터넷을 사용합니다.

**최신 버전: 0.8.0 · 빌드 14.** 새 기능과 핵심 테스트 98개, 렌더링·설정·날씨 서비스 검사, 실제 세 모니터의 데스크톱 통합 검사 76개를 통과했습니다. Apple Silicon·Intel 통합 앱과 DMG의 Developer ID 서명·Apple 공증을 마쳐 GitHub에 공개했으며 현재 Mac의 설치·실행도 확인했습니다. [0.8.0 변경 안내](docs/releases/0.8.0/RELEASE_NOTES.ko.md) · [검증 상태](docs/releases/0.8.0/VALIDATION.md)

Mac 버전의 완성도와 기능을 먼저 다듬은 뒤 Windows로 확장합니다. 현재 Windows 실행 파일은 제공하지 않습니다.

## 0.8.0에서 달라지는 점

- **앱별 표시 제외:** 선택한 앱의 창 안과 창 위의 효과를 숨깁니다. 실행 중인 앱 목록 또는 앱 파일 선택으로 추가하고 언제든 해제할 수 있습니다.
- **방향과 세기를 따로 조절하는 바람:** 왼쪽·오른쪽 방향과 0~100% 세기를 각각 선택합니다. 이전 버전의 바람 설정은 같은 유효 세기로 옮깁니다.
- **창과 바람에 반응하는 누적:** 창을 움직이면 가장자리 눈이 조금 흩어지고, 강한 바람에 쌓인 낙엽·벚꽃 일부가 다시 날립니다. 설정에서 이 반응을 끌 수 있습니다.
- **빗물의 작은 움직임:** 창에 닿은 비에 파문이 생기고 가까운 물방울이 합쳐져 커지면 떨어집니다.
- **반딧불·별가루:** 작은 빛이 천천히 움직이고 창 위에 잠시 머물다가 사라집니다.
- **눈사람 꾸미기:** 모자와 목도리 색을 각각 고르고 크기를 60~150%로 조절합니다. 기존 드래그와 화면별 위치 저장을 유지합니다.
- **빠른 제어와 시작:** 다른 앱 사용 중에도 단축키로 숨기기·복원, 30분 동안 숨기기, Mac 로그인 시 자동 실행과 시작 시 설정창 표시 옵션을 제공합니다.
- **실제 날씨 연동:** 도시를 선택하면 눈·비를 자동 반영합니다. 기본 꺼짐이며 직접 고른 효과는 30분 동안 유지합니다.

프리셋·날씨 소리·모니터마다 다른 효과는 이번 버전에 포함하지 않습니다. 모니터별 표시 여부는 기존처럼 개별 선택할 수 있습니다.

## 다운로드와 업데이트

소스와 배포는 [mindw96/WeatherWeather](https://github.com/mindw96/WeatherWeather) 저장소를 사용합니다. macOS 14 이상용 Apple Silicon·Intel 통합 앱을 제공합니다.

**0.8.0 다운로드:** [DMG](https://github.com/mindw96/WeatherWeather/releases/download/v0.8.0/WindowWeather-0.8.0-macOS-universal.dmg) · [앱만 담은 ZIP](https://github.com/mindw96/WeatherWeather/releases/download/v0.8.0/WindowWeather-0.8.0-macOS-universal.zip) · [릴리스 안내](https://github.com/mindw96/WeatherWeather/releases/tag/v0.8.0). 앱과 DMG 모두 서명·공증된 버전입니다.

DMG를 열고 앱을 옆의 `Applications` 폴더로 끌어 옮긴 다음 응용 프로그램 폴더에서 실행해 주세요. ZIP에는 앱 하나만 들어 있습니다. 한국어 환경의 표시 이름은 **쌓임쌓임**, 파일 이름은 `WindowWeather.app`입니다. 설치 후 Finder에서 DMG를 꺼내셔도 됩니다.

0.5.0부터 [Sparkle 2.10.1](https://github.com/sparkle-project/Sparkle/releases/tag/2.10.1)이 새 버전을 하루에 한 번 확인합니다. 설정의 **자동 업데이트 확인**에서 끌 수 있고, 설정창·앱 메뉴·메뉴 막대의 **업데이트 확인…**으로 직접 확인할 수 있습니다. 다운로드·설치는 사용자가 선택합니다. 0.5.0 이상은 앱 안에서 0.8.0 업데이트를 확인할 수 있습니다. 0.4.0 이하에는 업데이터가 없어 직접 설치해야 합니다.

`./script/release.sh`는 통합 Release 빌드 → Developer ID 서명 → 앱·DMG 공증 → 티켓 첨부 → Sparkle 업데이트 서명·검증 → 체크섬 생성을 진행합니다. 0.8.0 결과 경로는 `dist/releases/0.8.0/`이며 현재 완료 여부는 [검증 상태](docs/releases/0.8.0/VALIDATION.md)를 따릅니다. 중단 후에는 `--resume`으로 같은 제출을 이어갑니다. [배포 절차](docs/RELEASING.md)

## 개발 버전 실행하기

macOS 14 이상, Swift 5.9 이상이 포함된 Xcode 또는 Command Line Tools가 필요합니다. Sparkle를 처음 받는 빌드에는 인터넷 연결이 필요합니다. 의존성 버전과 체크섬은 고정되어 있습니다.

```sh
./script/build_and_run.sh
```

개발 빌드는 `dist/WindowWeather.app`과 `dist/WindowWeather-macOS.zip`에 생성합니다. 현재 Mac 아키텍처로 빌드하고 ad-hoc 서명을 적용하며, 배포용 공증 앱과 구분합니다. Codex의 Run 버튼도 이 스크립트를 사용합니다. 동기화 폴더의 Finder 메타데이터와 서명이 충돌하지 않도록 임시 로컬 폴더에서 서명합니다.

| 명령 | 용도 |
| --- | --- |
| `./script/build_and_run.sh --build-only` | 개발용 앱 번들 빌드 |
| `./script/build_and_run.sh --verify` | 빌드·실행 후 프로세스 확인 |
| `./script/build_and_run.sh --smoke` | 실제 테스트 창과 컨트롤러 통합 검사 |
| `./script/build_and_run.sh --previews` | 여덟 효과 미리보기와 곡면 렌더링 검사 |
| `./script/build_and_run.sh --validate-focus` | 포커스·앱별 숨김 렌더링 검사 |
| `./script/build_and_run.sh --validate-snowman` | 색·크기·클릭 영역·드래그·위치 복원 검사 |
| `./script/build_and_run.sh --validate-features` | 새 설정·마이그레이션·제어 기능 검사 |
| `./script/build_and_run.sh --validate-weather-service` | 실제 통신 없는 날씨 서비스 모의 응답 검사 |
| `swift test` | 핵심 시뮬레이션·창 경계·날씨 정책 테스트 |

SwiftPM의 중첩 샌드박스가 막히는 경우에만 `WEATHER_DISABLE_SWIFTPM_SANDBOX=1`을 붙입니다. 동기화 폴더의 빌드 캐시가 느릴 때는 `WEATHER_BUILD_DIR=/private/tmp/window-weather-build`로 빌드 위치를 바꿀 수 있습니다. 결과 앱은 그대로 `dist/`에 생성됩니다.

## 사용하기

설정창의 효과 선택 영역이나 메뉴에서 여덟 효과를 고르고 **내리는 양**, **바람 방향**, **바람 세기**, 누적 여부를 조절합니다. 바람 세기 0%는 바람의 영향을 끕니다. 쌓인 흔적을 지우거나 일시정지할 수 있으며 종료하면 오버레이가 사라집니다.

설정창을 닫거나 최소화한 뒤에는 **Dock 아이콘 클릭**, **Dock 오른쪽 클릭 → 설정 열기…**, **메뉴 막대 → 설정…**으로 다시 엽니다. 앱이 활성화된 상태에서는 **⌘,**도 사용할 수 있습니다. 설정창을 닫아도 효과는 계속되며 앱 메뉴의 종료 또는 **⌘Q**로 끝냅니다.

### 창과 모니터 표시

**효과를 표시할 모니터**에서 원하는 화면만 켜 주세요. 꺼진 화면의 효과와 눈사람은 사라지고 다시 켜면 새로 시작합니다. 선택은 저장되며 처음 연결한 화면은 기본 ON입니다. 모두 꺼도 설정창과 미리보기는 사용할 수 있습니다. [모니터 식별·미러링 안내](docs/DISPLAY_SELECTION.md)

**효과를 숨길 앱**에 추가한 앱의 창 안과 해당 창 위의 누적을 숨깁니다. **사용 중인 창에도 효과 표시**를 끄면 현재 작업 창도 숨깁니다. 이 두 설정은 독립적이며, 누적 상태를 삭제하지 않아 제외를 해제하거나 포커스를 바꾸면 남아 있는 효과가 다시 나타납니다. 눈사람도 숨긴 창과 겹치는 부분은 표시하거나 드래그 입력을 받지 않습니다.

접근성 권한 없이 활성 앱의 맨 앞 일반 창을 작업 창으로 판단합니다. 앱 전환 시와 약 200ms 주기로 갱신하며 별도 도구 패널·팝업은 실제 키보드 포커스 창과 다를 수 있습니다.

**전체 화면에서도 쌓기**는 기본 OFF입니다. 끄면 전체 화면·작업 영역을 가득 채운 최대화 창과 해당 화면 바닥에는 쌓이지 않으며 낙하 효과는 유지됩니다. 옵션을 끄는 순간 해당 창의 누적을 지웁니다. 화면 상단에 맞닿은 전체 화면 창의 누적은 안쪽에 표시합니다.

일반 창의 모서리는 OS 스타일에 맞춘 곡선으로 근사합니다. 뒤 창의 효과는 앞 창의 외곽을 따라 가려집니다. 독자적인 창 모양과는 차이가 날 수 있으며, 전체 화면으로 판단한 창과 화면 바닥은 평평하게 처리합니다. [곡률 구현 범위](docs/CORNER_GEOMETRY.md)

### 효과와 눈사람

눈·낙엽·벚꽃·색종이는 창 위에 쌓이고, 비는 물막·파문·물방울로 반응합니다. 비눗방울은 약 10초, 반딧불은 약 4초, 별가루는 약 8초 창 가장자리에 머물다가 사라집니다. **창과 바람에 쌓인 효과가 반응**을 켜면 창 이동에 눈이 흩어지고 강풍에 정착한 잎·꽃잎이 다시 날립니다.

**눈사람 표시**는 기본 ON이며 눈 모드에서만 나타납니다. 모자·몸통·팔을 잡아 같은 화면 안에서 이동할 수 있고 화면별 상대 위치를 저장합니다. **눈사람 꾸미기**에서 모자·목도리 색과 크기를 조절합니다. 다른 효과나 일시정지 상태에서는 숨기며, 쌓인 흔적 지우기와는 독립적입니다.

### 빠른 제어와 자동 시작

**어디서나 단축키로 숨기기·복원**은 기본 OFF입니다. 켜면 `⌃⌥⌘P`, `⌃⌥⌘Space`, `⌃⌥⌘S` 중 선택한 조합으로 다른 앱 사용 중에도 효과를 숨기고 복원합니다. 등록할 수 없는 조합은 설정에 오류를 표시하므로 다른 조합을 선택해 주세요. **30분 동안 숨기기**는 시간이 지나면 다시 표시합니다.

**Mac 로그인 시 자동 실행**을 켜면 다음 로그인부터 시작하도록 macOS에 등록합니다. 활성화할 때 **시작할 때 설정창 열기**를 끄며, 이후 원하는 값으로 바꿀 수 있습니다. 시스템 승인이 필요하면 설정의 버튼으로 macOS 로그인 항목 설정을 엽니다. 자동 실행은 사용자가 켜기 전까지 등록하지 않습니다.

### 실제 날씨

**실제 날씨에 맞춰 효과 바꾸기**는 기본 OFF입니다. 켠 뒤 도시를 검색·선택하면 약 15분마다 현재 날씨를 조회해 눈·비를 적용합니다. 강수가 없으면 **비·눈이 없을 때** 선택한 효과를 표시합니다. 수동으로 효과를 고르면 30분 동안 유지하며 **자동 연동 재개**로 즉시 돌아갈 수 있습니다.

조회 실패 시 최근 유효값을 잠시 유지하고, 날씨 기준 시각이 1시간을 넘으면 기본 효과로 돌아갑니다. 기준 시각과 연결 상태를 설정에서 확인할 수 있습니다. 도시 변경·연동 해제 뒤 늦게 도착한 이전 응답은 적용하지 않습니다. [날씨 공급자·동작·오프라인 처리](docs/WEATHER_INTEGRATION.md)

## 개인정보와 권한

- 창 정보 중 **위치·크기·창 ID·레이어·불투명도·소유 프로세스 ID**를 충돌·가림·활성 앱 식별에 사용합니다. 창 제목·내용이나 화면 이미지는 수집하지 않으며 창 목록과 프로세스 ID를 파일로 저장하지 않습니다.
- 앱별 제외 설정은 선택한 앱의 **번들 ID와 표시 이름**을 이 Mac에 저장합니다. 실행 중인 앱의 프로세스와 연결하는 데 사용하며 외부로 보내지 않습니다.
- 전역 단축키는 선택한 **특정 키 조합만 등록**합니다. 전체 키보드 입력을 감시하거나 기록하지 않습니다.
- 눈사람의 클릭 영역 판정에 포인터 위치를 메모리에서 사용합니다. 놓은 뒤에는 화면별 상대 위치를 저장하며 포인터 이동 기록은 남기지 않습니다.
- 실제 날씨 연동을 켠 뒤 도시 검색 시 **검색어**, 날씨 조회 시 **선택 도시의 좌표**와 일반적인 HTTPS 요청 정보가 Open-Meteo에 전달됩니다. 현재 위치 권한을 요청하거나 기기의 위치를 조회하지 않습니다. 날씨 응답은 메모리에만 보관하며 도시·연동 설정은 로컬에 저장합니다.
- 업데이트 확인은 GitHub Releases의 HTTPS 피드를 조회합니다. Sparkle 시스템 프로파일 전송은 꺼져 있고 날씨·도시·창·포인터 정보는 업데이트 요청에 포함하지 않습니다. 업데이트 ZIP은 EdDSA와 Apple 코드 서명으로 검증합니다.

화면 기록·Accessibility 권한을 요청하지 않습니다. 창이 감지되지 않으면 일반 앱 창을 열고 설정의 감지 상태를 확인해 주세요. 개인정보 처리와 데이터 출처를 포함한 [날씨 연동 안내](docs/WEATHER_INTEGRATION.md)를 제공합니다.

## 구현과 검증 범위

- **WeatherCore:** 플랫폼 창 API와 분리된 여덟 효과의 시뮬레이션, 곡면·가림·누적·화면 간 전달, 전체 화면 정책, 눈사람 위치, 실제 날씨 응답 검증과 전환 규칙입니다.
- **WeatherApp:** AppKit 투명 오버레이·창 추적, SwiftUI 설정, 단축키·자동 시작, 날씨 통신과 Sparkle 업데이트를 연결합니다. 일반 날씨 패널은 클릭을 통과시키며 눈사람의 보이는 몸체만 드래그 입력을 받습니다. 일반 상태 30Hz·저전력 상태 20Hz로 애니메이션을 갱신합니다.
- **검증:** 결정적 단위 테스트·오프스크린 그림 검사·네이티브 테스트 창·공개 샘플 API 점검을 구분합니다. [0.8.0 검증 상태](docs/releases/0.8.0/VALIDATION.md)와 [PLAN.md](PLAN.md)에 완료 여부를 기록합니다.

실제 입력·다양한 앱의 겹침·Mission Control·Spaces·전체 화면·모니터 배율 조합·잠자기 복귀는 별도 실사용 확인 대상입니다. API의 한 번 성공이나 테스트 이미지가 모든 데스크톱 환경의 동작을 보장하지 않습니다. Dock 위 적설과 번개는 포함하지 않습니다.

## 설계 자료와 이전 버전

[REA.md](REA.md)는 지정된 Koi 앱의 정적 분석 근거와 한계를, [PLAN.md](PLAN.md)는 구현 단계와 남은 검증을 기록합니다. Koi의 코드·셰이더·아이콘·배경·음원을 사용하지 않습니다.

이전 검증 기록: [0.6.2 곡률·비 가시성](docs/releases/0.6.2/VALIDATION.md) · [0.6.3 창 겹침](docs/releases/0.6.3/VALIDATION.md) · [0.7.0 모니터 선택](docs/releases/0.7.0/VALIDATION.md) · [0.7.1 아이콘](docs/releases/0.7.1/VALIDATION.md) · [0.7.2 흰 테두리 제거](docs/releases/0.7.2/VALIDATION.md). [아이콘 원본과 재생성](branding/README.md)을 보관합니다.

Windows는 Mac 품질 개선 이후 진행합니다. Swift Windows에서 공통 엔진의 빌드·테스트 호환성을 먼저 확인하고 창 열거·투명 오버레이·DPI·렌더링은 별도로 구현할 계획입니다.
