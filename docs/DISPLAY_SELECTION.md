# 모니터 선택 — 0.7.0

설정창의 **효과를 표시할 모니터**에서 연결된 화면마다 날씨를 켜고 끕니다. 기존처럼 모든 모니터를 켜 둔 상태가 기본값이며, 처음 연결한 모니터도 켜집니다. 눈·비·낙엽·벚꽃·비눗방울·색종이와 화면 아래 눈사람에 공통으로 적용됩니다.

## 선택과 저장

`Preferences.disabledDisplayIDs`에 끈 화면의 식별자만 저장합니다. 선택 기준은 모니터 이름·목록 번호·좌표가 아니라 `DisplayIdentity.key(for:)`가 반환하는 디스플레이 UUID입니다. 목록 번호와 이름·해상도·주 디스플레이 표시는 사용자가 연결된 화면을 구분하기 위한 안내입니다.

분리된 화면의 식별자를 지우지 않으므로 같은 UUID로 다시 연결하면 선택을 복원합니다. 앱 재실행도 같은 설정을 읽습니다. UUID가 제공되지 않으면 현재 세션의 화면 ID로 대체합니다. 이 예외에서는 재연결이나 재부팅 뒤 선택이 달라질 수 있으며, 코드의 `shortcut:` 주석에도 한계를 명시합니다.

## 끄기와 다시 켜기

화면을 끄면 해당 화면의 투명 날씨 패널과 눈사람 패널을 숨깁니다. 내리던 입자·튀는 물방울·쌓인 흔적은 초기화하고, 꺼진 화면의 시뮬레이션 갱신과 창 표면 계산은 건너뜁니다. 다시 켜면 기존 누적을 되살리지 않고 새로 내립니다. 저장된 눈사람 위치와 전역 날씨 설정은 유지합니다.

모든 화면을 끄면 날씨 애니메이션·창 추적 타이머도 정지합니다. 설정창과 미리보기는 사용할 수 있으며 목록에서 화면을 다시 켜면 재개합니다. 전역 **잠시 멈추기**가 켜져 있으면 화면을 선택하더라도 날씨는 일시정지 상태를 유지합니다.

화면 연결·분리 알림에 따라 목록과 표시 대상을 갱신합니다. 모니터 재구성 때의 입자·누적 초기화와 화면별 선택 저장은 별개이며, 재연결 시 이전 눈더미를 복원하는 기능은 아닙니다.

## 미러링과 검증 경계

선택 단위는 `NSScreen.screens`로 macOS가 제공하는 논리 화면입니다. 미러링으로 같은 데스크톱을 보여 주는 물리 모니터에 서로 다른 날씨 표시를 지정하지는 않습니다. 서로 다른 화면을 따로 제어하려면 macOS에서 확장 디스플레이로 구성해야 합니다.

[0.7.0 검증 기록](releases/0.7.0/VALIDATION.md)에 실제 수행한 결과를 정리합니다. 저장된 UUID와 연결 알림을 이용한 재현 검사가 모든 허브·모니터·미러링 환경의 실제 재연결을 입증하지는 않습니다.
