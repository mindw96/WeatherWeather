# 둥근 창 상단 — 0.6.2

2026-11-06. 첨부 화면에서 창의 둥근 모서리 위로 적설선이 일직선으로 떠 보이는 문제를 개선합니다.

## 공개 API와 구현 범위

현재 사용하는 CGWindowListCopyWindowInfo의 [kCGWindowBounds](https://developer.apple.com/documentation/coregraphics/kcgwindowbounds)는 사각형 위치와 크기를 제공합니다. 다른 앱 창의 코너 반경·외곽 경로는 제공하지 않습니다. ScreenCaptureKit의 [SCWindow.frame](https://developer.apple.com/documentation/screencapturekit/scwindow/frame)도 사각형입니다. [Apple WWDC25의 AppKit 디자인 설명](https://developer.apple.com/videos/play/wwdc2025/310/)은 도구 막대 유무와 크기에 따라 모서리 곡률이 달라진다고 설명합니다. 하나의 OS 반경이 모든 창에서 정확하다고 간주할 수 없습니다.

별도 화면 기록·접근성 권한 없이 macOS 26 이상은 16pt, 이전 버전은 10pt의 추정 반경을 사용합니다. 이 숫자는 이 앱의 시각적 근사값이며 Apple이 보장하는 상수가 아닙니다. 창 폭·높이에 맞춰 제한합니다. 독자적인 외곽이나 각진 창에는 오차가 남습니다. 실제 창 내용이나 이미지를 캡처·분석하지 않습니다.

## 0.6.2 보정

사용자가 제공한 확대 화면에서 회색 창 경계의 반경은 약 30~32픽셀, 빨간 창 버튼의 지름은 약 24픽셀로 관측했습니다. 배율을 직접 조회한 값은 아니지만 2배 이미지로 해석하면 약 15~16pt입니다. 기존 26pt 곡선이 실제 창보다 넓게 돌아가는 현상이 보여 기본값을 16pt로 줄였습니다. 흐림과 물막이 일부 경계를 가리므로 정확한 앱별 반경을 측정했다고 보지 않습니다. 기존 원호 계산은 유지하고, macOS 26 이전의 10pt 기본값은 그대로 둡니다.

## 공통 곡선

창·표면·누적 상태에 반경을 전달하고, 상단 양 끝을 원호로 표현합니다. 눈·물막의 윗면과 밑면, 여섯 효과의 충돌, 개별 조각의 정착 위치가 같은 표면 높이를 사용합니다. 눈의 두께는 기존 가장자리 taper를 유지합니다. 화면 바닥과 전체 화면 정책이 판정한 창은 반경 0입니다.

입자 이동은 지나간 선분과 곡선 표본 사이의 교차를 검사하여 빠른 빗방울이나 모서리 방향 바람이 평평한 가상 표면에 부딪히지 않도록 합니다. 누적량과 정착 오프셋은 곡선으로부터의 상대 높이이므로 창 이동·크기 변경·모니터 이동에도 새 곡선을 따릅니다.

앞 창의 가림과 작업 창 효과 숨김은 기존의 보수적인 사각형 경계를 유지합니다. 앞 창의 둥근 빈 틈을 통해 뒤 창 효과를 노출하는 것까지 구현하지 않습니다.

## 검증

핵심 곡선·충돌 테스트와 생성한 모서리 전후 비교, 렌더링·실제 테스트 창 추적 검증을 수행합니다. 0.6.1의 [곡면 도입 검증](releases/0.6.1/VALIDATION.md)과 0.6.2의 [보정 검증](releases/0.6.2/VALIDATION.md)을 구분합니다. 미리보기는 다른 앱의 화면 캡처가 아닌 자체 생성한 예시이며, 모든 앱의 실제 곡률 일치를 입증하지 않습니다.
