# 쌓임쌓임 지원

쌓임쌓임(Window Weather)은 macOS 14 이상에서 사용하는 계절 효과 앱입니다. 회원가입·로그인 없이 이용할 수 있습니다.

## 설정 열기와 빠른 제어

- Dock의 쌓임쌓임 아이콘을 누르거나 메뉴 막대에서 **설정…**을 선택합니다. 앱이 활성화된 상태에서는 **⌘,**도 사용할 수 있습니다.
- **잠시 멈추기**는 효과를 숨기며 **다시 내리기**로 복원합니다. **30분 동안 숨기기**는 시간이 지나면 자동 복원합니다.
- 바람 방향의 **가운데(없음)**은 바람을 끕니다. 왼쪽·오른쪽을 다시 선택하면 저장한 세기를 사용합니다.
- **효과를 표시할 모니터**, **사용 중인 창에도 효과 표시**, **효과를 숨길 앱**을 확인해 원하는 창과 화면에 표시하도록 설정합니다.
- **전체 화면에서도 쌓기**는 전체 화면·최대화 창의 누적 여부를 조절합니다.
- 눈 모드의 눈사람은 모자·몸·팔을 잡아 옮길 수 있습니다. 모자·목도리 색과 크기는 설정에서 바꿉니다.

## 실제 날씨가 맞지 않을 때

실제 날씨는 기본적으로 꺼져 있습니다. 설정에서 켠 뒤 도시를 검색하고 국가·지역까지 확인해 선택해 주세요. 기기의 현재 위치는 조회하지 않습니다.

연동은 약 15분마다 갱신합니다. **지금 날씨 확인**으로 다시 조회할 수 있습니다. 직접 다른 효과를 고르면 30분 동안 그 선택을 유지하며 **자동 연동 재개**로 즉시 돌아갈 수 있습니다. 연결 실패 시 최근 유효값을 잠시 유지하고, 날씨 기준 시각이 1시간을 넘으면 기본 효과를 사용합니다. 모델 기반 정보이므로 창밖의 상황과 차이가 날 수 있습니다.

전송 항목과 공급자의 보관 정책은 [개인정보 처리방침](PRIVACY.md), 동작 기준은 [날씨 연동 안내](WEATHER_INTEGRATION.md)를 참고해 주세요.

## 자동 실행과 업데이트

**Mac 로그인 시 자동 실행**을 직접 켜야 자동 실행됩니다. 시스템 승인이 필요한 경우 앱이 제공하는 버튼으로 macOS 로그인 항목 설정을 열 수 있습니다. **시작할 때 설정창 열기**는 따로 선택할 수 있습니다.

App Store에서 설치한 앱은 App Store에서 업데이트합니다. GitHub 직접 배포판은 앱의 **업데이트 확인…**을 사용합니다.

문의는 공개될 수 있습니다. 비밀번호·인증서·API 키는 게시하지 마세요. 앱 사용에는 계정이 필요하지 않지만 GitHub 문의 작성에는 GitHub 계정이 필요할 수 있습니다.
