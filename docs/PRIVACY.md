# 쌓임쌓임 개인정보 처리방침

적용 대상: 쌓임쌓임(Window Weather) **Mac App Store 배포판 1.0.0 이후**  
마지막 수정: 2026-11-11

쌓임쌓임은 회원가입 없이 창 위에 계절 효과를 표시하는 앱입니다. 개발자는 앱 사용을 위한 계정 서버, 광고, 행동 분석 또는 추적 서비스를 운영하지 않습니다. 수동 효과는 인터넷 없이 동작합니다.

## 이 Mac에서 처리하는 정보

앱은 선택한 효과, 바람, 모니터 선택, 눈사람 위치·모양, 제외할 앱, 단축키, 시작 설정과 선택한 도시를 macOS의 앱 설정 저장소에 보관합니다. 로그인 자동 실행은 사용자가 켰을 때 macOS의 로그인 항목 기능으로 관리합니다.

효과를 창 가장자리에 표시하기 위해 화면과 창의 위치·크기·식별자, 창 소유 앱의 프로세스 식별자와 활성 앱을 이 Mac에서 처리합니다. 제외 앱 선택에는 실행 중인 앱의 이름·번들 식별자를 사용하며, 직접 선택한 앱 파일에서는 이름과 번들 식별자를 읽습니다. 눈사람 드래그는 이 Mac의 포인터 위치를 사용합니다. 이 정보와 앱 설정은 날씨 서버나 개발자에게 전송하지 않습니다.

앱은 다른 앱의 창 제목·화면 내용·문서·입력한 글을 수집하거나 화면을 녹화하지 않습니다. 전역 단축키는 선택한 조합만 등록하며 일반 키 입력을 기록하지 않습니다.

## 선택 기능: 실제 날씨

실제 날씨 연동의 기본값은 꺼짐입니다. 사용자가 켜고 도시를 검색·선택하면 다음 정보를 HTTPS로 Open-Meteo에 보냅니다.

- 도시 검색 시: 입력한 도시 검색어를 `geocoding-api.open-meteo.com`에 전송합니다.
- 현재 날씨 조회 시: 선택 도시의 위도·경도를 `api.open-meteo.com`에 전송합니다. 자동 조회는 약 15분 간격이며 수동 새로고침도 가능합니다.
- 서비스 제공자는 연결 과정에서 IP 주소 등 일반적인 네트워크 요청 정보를 받습니다.

기기의 현재 위치를 조회하거나 위치 권한을 요청하지 않습니다. 전송하는 좌표는 사용자가 선택한 도시의 좌표입니다. 앱은 검색 기록을 디스크에 저장하지 않으며, 날씨 요청에 계정·광고 식별자·창 정보를 넣지 않습니다. 날씨 응답은 실행 중 메모리에서 사용하고, 세션의 디스크 캐시와 쿠키 저장소는 사용하지 않습니다.

Open-Meteo의 무료 API 정책은 기술 운영·오용 방지를 위한 IP 처리와, 좌표가 포함될 수 있는 문제 해결용 로그를 설명합니다. 제공자는 사용자 신원과 연결하지 않고 제3자에게 공유하지 않으며 로그를 **90일 후 삭제**한다고 밝힙니다. 이는 제공자의 정책이며 개발자가 해당 서버 로그를 보유하거나 직접 삭제하지 않습니다. 무료 API가 도시 검색어 자체를 얼마나 보관하는지는 별도로 명시되어 있지 않습니다. [Open-Meteo 이용 약관과 개인정보 안내](https://open-meteo.com/en/terms)

## 선택 변경·보관·삭제

설정에서 실제 날씨 연동을 끄면 새 도시 검색·날씨 요청을 중단하고 진행 중 요청을 취소합니다. 이미 제공자에게 전달된 요청이나 로그가 즉시 삭제되는 것은 아닙니다. 연동을 꺼도 선택 도시와 기존 앱 설정은 이 Mac에 남아 다음 사용 시 복원됩니다.

앱 설정은 사용자가 변경할 때까지 로컬에 보관합니다. 앱을 종료한 뒤 macOS가 앱에 할당한 설정·컨테이너 데이터를 삭제하면 해당 로컬 정보를 제거할 수 있습니다. 앱 파일만 삭제할 경우 설정이 남을 수 있으므로 전체 초기화 안내는 [지원 페이지](SUPPORT.md)를 통해 요청하실 수 있습니다. 개발자는 원격으로 이 Mac의 설정을 열람하거나 삭제할 수 없습니다.

Open-Meteo가 보관하는 정보에 대한 열람·삭제 문의는 해당 제공자의 [개인정보 안내에 있는 연락처](https://open-meteo.com/en/terms)를 이용해 주세요.

## App Store와 외부 링크

App Store 배포판의 다운로드·업데이트는 Apple이 처리하며 앱 안에 Sparkle 업데이트 기능을 포함하지 않습니다. Apple의 처리에 대해서는 [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/)이 적용됩니다. 이 문서는 별도 Sparkle 업데이터를 사용하는 GitHub 직접 배포판의 방침을 대신하지 않습니다.

지원·문서 링크를 열면 기본 웹 브라우저에서 외부 웹사이트로 이동합니다. 공개 GitHub 문의에 직접 작성한 내용은 다른 사람이 볼 수 있으므로 암호·API 키·개인 문서나 불필요한 개인정보를 게시하지 마세요.

## 문의와 변경

앱 지원 및 개인정보 문의 창구는 [WeatherWeather GitHub Issues](https://github.com/mindw96/WeatherWeather/issues)입니다. 앱 사용에는 계정이 필요하지 않으며, GitHub에 문의를 작성할 때에는 GitHub 계정이 필요할 수 있습니다.

앱의 데이터 처리 방식이 바뀌면 이 문서의 적용 내용과 수정 날짜를 갱신합니다.
