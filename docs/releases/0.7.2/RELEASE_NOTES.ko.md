# 쌓임쌓임 0.7.2

앱 아이콘 바깥의 흰 테두리를 제거하는 버전입니다. 기존 창·눈 모양을 유지하고 파랑·청록 배경이 아이콘 가장자리까지 이어지도록 수정합니다.

배포 상태: 앱과 DMG의 Developer ID 서명·Apple 공증·티켓 첨부 및 Sparkle 업데이트 서명 검증을 완료했습니다.

## 이번 변경

- **흰 테두리 제거:** 로고의 바깥 흰 여백을 없애고 파랑·청록 배경으로 채운 새 원본을 사용합니다.
- **앱 아이콘 확인:** 개발·배포 번들에 같은 아이콘을 연결하고, macOS가 둥근 외곽을 적용한 실제 아이콘 표시를 확인합니다.

이번 변경은 아이콘 외곽 수정입니다. 기존 여섯 날씨 효과, 모니터 선택, 전체 화면·작업 창 표시 옵션, 눈사람 위치 저장과 Sparkle 업데이트 기능은 같은 사용법을 따릅니다.

## 다운로드와 설치

[0.7.2 릴리스 페이지](https://github.com/mindw96/WeatherWeather/releases/tag/v0.7.2)에 macOS 14 이상용 Apple Silicon·Intel 통합 DMG와 앱만 담은 ZIP을 제공합니다.

0.5.0 이상에서는 앱의 **업데이트 확인…**으로 배포된 새 버전을 확인하실 수 있습니다. 직접 설치하려면 기존 앱을 종료하고 DMG의 앱을 Applications로 옮겨 주세요. ZIP에는 앱 하나만 들어 있습니다.

설정창은 Dock 아이콘, 메뉴 막대의 **설정…**, **⌘,**로 열 수 있습니다. [사용 안내](https://github.com/mindw96/WeatherWeather/blob/main/docs/releases/0.7.2/START_HERE.ko.txt)를 제공합니다.

[검증 기록](https://github.com/mindw96/WeatherWeather/blob/main/docs/releases/0.7.2/VALIDATION.md)에 원본·ICNS·시스템 아이콘 표시, 배포 파일과 업데이트 확인 결과를 구분합니다.
