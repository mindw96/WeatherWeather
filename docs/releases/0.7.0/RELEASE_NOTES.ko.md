# 쌓임쌓임 0.7.0

날씨 효과를 표시할 모니터를 선택할 수 있습니다. macOS 14 이상용 Apple Silicon·Intel 통합 앱입니다.

배포 상태: 앱과 DMG의 Developer ID 서명·Apple 공증·티켓 첨부 및 Sparkle 업데이트 서명 검증을 완료했습니다.

## 이번 변경

- **모니터별 표시:** 설정창의 **효과를 표시할 모니터**에서 화면마다 켜고 끌 수 있습니다. 번호·이름·해상도·주 디스플레이 표시로 화면을 구분합니다.
- **선택 저장:** 처음에는 모든 화면이 켜져 있습니다. 화면별 선택을 저장하고 분리된 모니터의 기록도 유지합니다. 처음 연결한 화면은 기본적으로 켜집니다.
- **화면별 정지:** 끈 화면의 날씨·쌓인 흔적·눈사람을 숨기고 시뮬레이션을 멈춥니다. 그 화면의 입자와 누적은 초기화되며 다시 켜면 새로 내립니다.
- **설정창 스크롤:** 연결된 화면 목록을 자동 갱신하며, 작은 화면에서도 모든 설정에 접근할 수 있도록 스크롤을 지원합니다. 모두 끈 상태에서도 설정창과 미리보기는 사용할 수 있습니다.

여섯 효과에 공통으로 적용됩니다. 기존 전체 화면·작업 창 표시 옵션과 눈사람 위치 저장을 유지합니다. [동작과 한계](https://github.com/mindw96/WeatherWeather/blob/main/docs/DISPLAY_SELECTION.md)를 정리했습니다.

## 다운로드와 설치

[0.7.0 릴리스 페이지](https://github.com/mindw96/WeatherWeather/releases/tag/v0.7.0)의 DMG와 앱만 담은 ZIP을 사용하실 수 있습니다.

0.5.0 이상에서는 앱의 **업데이트 확인…**으로 배포된 새 버전을 확인하실 수 있습니다. 직접 설치하려면 기존 앱을 종료하고 DMG의 앱을 Applications로 옮겨 주세요. ZIP에는 앱 하나만 들어 있습니다.

설정창은 Dock 아이콘, 메뉴 막대의 **설정…**, **⌘,**로 열 수 있습니다. [사용 안내](https://github.com/mindw96/WeatherWeather/blob/main/docs/releases/0.7.0/START_HERE.ko.txt)를 제공합니다.

선택은 macOS의 논리 화면 단위입니다. 미러링된 같은 화면을 물리 모니터별로 다르게 표시하지는 않습니다. UUID가 없는 화면은 재연결 후 선택이 달라질 수 있습니다. Intel Mac·macOS 14 실기기와 모든 연결·배율 조합은 별도 검증이 필요합니다.
