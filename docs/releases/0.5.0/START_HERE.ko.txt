Window Weather 0.5.0 — 사용 안내

창 위에 눈, 비, 가을 낙엽, 봄 벚꽃을 내리는 작은 Mac 앱입니다.
회원가입·로그인 없이 사용하실 수 있습니다. 날씨 효과는 인터넷 연결 없이
동작하며, 새 버전 확인과 다운로드에만 인터넷을 사용합니다.

지원 환경과 배포 상태
• macOS 14 이상
• Apple Silicon(arm64)·Intel(x86_64) 통합 앱입니다.
  Intel Mac과 macOS 14 실기기에서의 실행은 아직 확인하지 않았습니다.
• Windows용 앱은 아직 제공하지 않습니다.

배포 상태: Developer ID 서명과 Apple 공증을 완료했습니다.

실행하기
1. 기존 버전이 실행 중이면 해당 앱의 메뉴 막대에서 ‘종료’를 선택해 주세요.
2. DMG를 열고 WindowWeather.app을 옆의 Applications 폴더로 끌어 옮긴 뒤,
   응용 프로그램 폴더에서 실행해 주세요. 설치 후 Finder에서 DMG를 꺼내셔도 됩니다.
   ZIP으로 받으셨다면 압축을 풀어 나온 앱 하나를 응용 프로그램 폴더에 옮깁니다.
3. 처음 실행하면 설정창이 열립니다. 눈 / 비 / 낙엽 / 벚꽃을 선택해 주세요.

업데이트 확인
• Sparkle 2.10.1로 새 버전을 확인합니다.
• 설정창 아래의 ‘자동 업데이트 확인’은 기본 ON입니다. 앱이 실행 중일 때
  하루에 한 번 새 버전을 확인하며, 원하시면 스위치를 끄실 수 있습니다.
• 지금 확인하려면 설정창의 ‘업데이트 확인…’, 앱 메뉴 또는 메뉴 막대의
  ‘업데이트 확인…’을 선택합니다.
• 새 버전이 있으면 안내가 나타납니다. 다운로드와 설치는 직접 선택합니다.
• 0.4.0 이하 버전에는 업데이트 기능이 없어 이번 0.5.0은 DMG 또는 ZIP을 받아
  직접 설치해 주세요. 0.5.0부터 이후 버전을 앱 안에서 확인할 수 있습니다.
• 업데이트는 GitHub의 mindw96/WeatherWeather 배포에서 제공됩니다.
  오프라인이어도 기존 날씨 효과와 설정은 계속 사용할 수 있습니다.

설정창 다시 열기
• 앱이 실행 중일 때 Dock의 Window Weather 아이콘을 클릭합니다.
• Dock 아이콘을 오른쪽 클릭하고 ‘설정 열기…’를 선택할 수도 있습니다.
• 화면 위 메뉴 막대의 날씨 아이콘 → ‘설정…’에서도 열 수 있습니다.
• Window Weather가 활성 앱이면 상단 ‘Window Weather’ 메뉴 → ‘설정…’
  또는 Command + 쉼표(⌘,)를 사용합니다.
• 설정창을 닫거나 최소화해도 위 방법으로 다시 열 수 있습니다.
  메뉴 막대 아이콘을 찾기 어려운 경우 Dock을 이용해 주세요.

눈사람 사용
• 설정에서 ‘눈’을 선택하면 각 화면의 오른쪽 아래에 눈사람이 나타납니다.
• ‘눈사람 표시’는 기본적으로 켜져 있습니다. 끄면 눈사람만 숨깁니다.
• 비·낙엽·벚꽃 모드에서는 눈사람이 숨겨지고 이 스위치는 비활성화됩니다.
  다시 눈 모드로 돌아오면 저장된 표시 설정을 따릅니다.
• 눈사람의 모자·몸·팔을 마우스로 잡아 끌면 같은 화면 안에서 옮길 수 있습니다.
  화면 밖으로 벗어나지 않으며, 화면 사이를 넘겨 옮기는 기능은 제공하지 않습니다.
• 놓은 위치는 화면별로 저장됩니다. 화면 크기가 바뀌면 화면 안의 상대 위치를
  기준으로 복원합니다. 아직 저장한 위치가 없는 화면은 오른쪽 아래에서 시작합니다.
• ‘쌓인 흔적 지우기’는 눈사람을 지우거나 저장한 위치를 초기화하지 않습니다.
• ‘사용 중인 창에도 효과 표시’를 끄면 작업 창과 겹치는 눈사람 부분도 숨겨집니다.
  숨겨진 부분으로는 드래그를 시작할 수 없습니다.
• 설정창의 미리보기에도 표시 여부가 반영됩니다. 위치를 옮기는 드래그는
  실제 데스크톱의 눈사람에서 사용해 주세요.

기본 사용 방법
• 설정창이나 메뉴 막대에서 눈 / 비 / 낙엽 / 벚꽃을 선택합니다.
• 내리는 양·바람·누적 여부와 전체 화면에서 쌓일지 선택하실 수 있습니다.
• ‘사용 중인 창에도 효과 표시’를 끄면 작업 창 안의 효과와 그 창의 누적을
  숨깁니다. 다른 창으로 전환하거나 다시 켜면 남아 있는 효과가 보입니다.
• ‘잠시 멈추기’는 눈사람을 포함한 효과를 숨깁니다. ‘다시 내리기’로 재개합니다.
• 설정창을 닫아도 효과는 계속됩니다. 효과와 앱을 모두 끝내려면
  메뉴 막대의 ‘종료’ 또는 앱 메뉴의 ‘Window Weather 종료’를 선택합니다.
  Window Weather가 활성 앱일 때 Command + Q(⌘Q)로 종료할 수도 있습니다.

현재 사용 중인 앱의 맨 앞 일반 창을 작업 창으로 판단합니다. 일부 보조 패널이나
특수한 창에서는 실제 입력을 받는 창과 다르게 판단할 수 있습니다.

삭제하려면 메뉴 막대에서 앱을 종료한 뒤 WindowWeather.app을 휴지통으로
옮겨 주세요. 새로 작성한 앱 소스는 MIT 라이선스를 따릅니다.
