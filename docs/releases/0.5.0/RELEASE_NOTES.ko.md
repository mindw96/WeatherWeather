# Window Weather 0.5.0

2026년 11월 5일 버전입니다. macOS 14 이상용 Apple Silicon(arm64)·Intel(x86_64) 통합 앱입니다. 계정 없이 사용할 수 있으며, 날씨 효과는 오프라인에서도 동작합니다.

배포 상태: Developer ID 서명과 Apple 공증을 완료했습니다.

## 새 기능: Sparkle 업데이트 확인

- Sparkle 2.10.1을 사용해 새 버전을 확인합니다.
- 설정의 **‘자동 업데이트 확인’**은 기본 ON이며 끄실 수 있습니다. 앱이 실행 중일 때 하루에 한 번 확인합니다.
- 설정창, 상단 앱 메뉴, 메뉴 막대 날씨 메뉴의 **‘업데이트 확인…’**으로 직접 확인할 수도 있습니다.
- 새 버전이 있으면 안내를 표시합니다. 다운로드와 설치는 사용자가 선택합니다.
- 업데이트 확인과 다운로드에만 인터넷을 사용합니다. 날씨 효과에 계정이나 서버 연결이 필요하지 않습니다.
- 업데이트 배포 위치는 [GitHub mindw96/WeatherWeather](https://github.com/mindw96/WeatherWeather)입니다.

**0.4.0에는 업데이트 기능이 없으므로 이번 0.5.0은 ZIP을 받아 직접 설치해 주세요.** 기존 앱을 종료하고 새 `WindowWeather.app`으로 교체합니다. 계속 사용하실 경우 응용 프로그램 폴더에 두시는 것이 편합니다. 저장된 날씨 설정과 눈사람 위치는 유지합니다.

## 성능 개선

- 창 위치와 크기가 그대로이면 누적 상태 배열을 다시 만드는 처리를 생략합니다.
- 입자가 도달할 수 없는 창에는 상세 충돌 계산을 하지 않습니다.
- 낙엽과 벚꽃을 그릴 때 반복하던 기본 도형 생성을 줄였습니다.

동일한 입력으로 변경 전후를 비교했으며 시뮬레이션 상태와 검사한 이미지가 같음을 확인했습니다. 정해진 합성 부하에서 Core 시뮬레이션 시간은 약 32–50%, 낙엽·벚꽃의 화면 밖 렌더링 시간은 각각 약 14%·21% 줄었습니다. 앱 전체 CPU·배터리 사용량의 감소율을 뜻하지 않으며 실제 화면 구성에 따라 차이가 있습니다. 자세한 조건과 원시 결과는 저장소의 `docs/PERFORMANCE.md`를 참고해 주세요.

## 기존 기능

눈·비·낙엽·벚꽃, 전체 화면 누적 선택, 작업 창 효과 표시 선택, 눈사람 표시·드래그 위치 저장, 강도·바람 조절, 일시정지와 누적 지우기를 계속 제공합니다. 설정창은 Dock 아이콘 클릭, Dock 오른쪽 클릭 → **‘설정 열기…’**, 메뉴 막대의 **‘설정…’**, 앱이 활성 상태일 때 **⌘,**로 다시 열 수 있습니다. 설정창을 닫아도 효과는 계속되며 **⌘Q** 또는 메뉴의 종료로 앱을 끝냅니다.

## 개인정보와 현재 범위

설정과 화면별 눈사람 위치는 Mac에 저장합니다. 창 제목·내용·화면 이미지·키보드 입력은 수집하거나 업데이트 서버로 전송하지 않습니다. 업데이트 확인은 배포 서버와 연결하며 서버는 일반적인 요청 정보(IP 주소 등)를 받을 수 있습니다.

Intel Mac과 macOS 14 실기기 실행, 실제 마우스 입력 전달, 모든 Spaces·배율 조합의 검증은 별도입니다. 눈사람은 원래 화면 안에서 움직이며 다른 모니터로 넘겨 옮기지는 않습니다. Windows 앱은 아직 제공하지 않습니다.

새로 작성한 앱 코드는 MIT 라이선스를 따릅니다. Sparkle은 동봉된 Sparkle 라이선스를 따릅니다. Koi의 코드·이미지·음원은 포함하지 않습니다.
