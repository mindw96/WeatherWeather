# 쌓임쌓임 0.7.1

쌓임쌓임의 새 로고를 앱 아이콘으로 사용하는 버전입니다. 둥근 창 두 개 위에 눈이 쌓이는 모습을 파랑·청록과 하얀색으로 표현했습니다.

배포 상태: 앱과 DMG의 Developer ID 서명·Apple 공증·티켓 첨부 및 Sparkle 업데이트 서명 검증을 완료했습니다.

## 이번 변경

- **새 앱 아이콘:** Finder와 Dock에서 쌓임쌓임의 창·눈 로고로 앱을 구분할 수 있도록 적용합니다.
- **개발·배포 번들:** 같은 아이콘 리소스를 개발용 앱과 공유용 앱에 연결합니다.

이번 변경은 앱 아이콘 적용입니다. 기존 여섯 날씨 효과, 모니터 선택, 전체 화면·작업 창 표시 옵션, 눈사람 위치 저장과 Sparkle 업데이트 기능은 그대로 사용합니다.

## 다운로드와 설치

[0.7.1 릴리스 페이지](https://github.com/mindw96/WeatherWeather/releases/tag/v0.7.1)에 macOS 14 이상용 Apple Silicon·Intel 통합 DMG와 앱만 담은 ZIP을 제공합니다.

0.5.0 이상에서는 앱의 **업데이트 확인…**으로 배포된 새 버전을 확인하실 수 있습니다. 직접 설치하려면 기존 앱을 종료하고 DMG의 앱을 Applications로 옮겨 주세요. ZIP에는 앱 하나만 들어 있습니다.

설정창은 Dock 아이콘, 메뉴 막대의 **설정…**, **⌘,**로 열 수 있습니다. [사용 안내](https://github.com/mindw96/WeatherWeather/blob/main/docs/releases/0.7.1/START_HERE.ko.txt)를 제공합니다.

[검증 기록](https://github.com/mindw96/WeatherWeather/blob/main/docs/releases/0.7.1/VALIDATION.md)에 아이콘 표시·설치 파일·업데이트 확인 결과와 아직 확인하지 않은 환경을 구분합니다.
