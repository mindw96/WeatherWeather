쌓임쌓임 0.6.1 — 사용 안내

창 위에 눈·비·낙엽·벚꽃·비눗방울·색종이를 표시하는 Mac 앱입니다.
회원가입이나 로그인 없이 사용할 수 있으며 효과는 오프라인에서도 동작합니다.
한국어 환경의 앱 표시 이름은 ‘쌓임쌓임’, 영문 이름은 ‘Window Weather’입니다.
앱 파일 이름은 WindowWeather.app입니다.

지원 환경
• macOS 14 이상, Apple Silicon(arm64)·Intel(x86_64) 통합 앱입니다.
• Intel Mac과 macOS 14 실기기 실행은 별도 확인이 필요합니다.
• Windows 앱은 아직 제공하지 않습니다.

배포 상태: Developer ID 서명·Apple 공증과 공개 배포 파일 검증을 완료했습니다.

처음 설치하기
1. 기존 앱이 실행 중이면 메뉴 막대의 ‘종료’ 또는 Command + Q(⌘Q)로 종료합니다.
2. DMG를 열고 앱을 옆의 Applications 폴더로 끌어 옮깁니다.
   ZIP을 받으셨다면 압축을 풀어 나온 앱 하나를 응용 프로그램 폴더에 옮깁니다.
3. 응용 프로그램 폴더에서 앱을 실행합니다. 설치 후 Finder에서 DMG를 꺼내셔도 됩니다.
4. 설정창의 두 줄 선택 영역에서 원하는 효과를 선택해 주세요.

둥근 창 모서리
• 눈·물막과 나머지 네 효과가 같은 둥근 상단 곡선을 따라 닿고 쌓입니다.
• 화면 바닥과 전체 화면으로 판정한 창의 상단은 평평하게 유지합니다.
• 다른 앱의 실제 곡률을 읽는 공개 API가 없어 OS 스타일에 맞춘 추정값입니다.
  독자적인 창 모양이나 사각 창에서는 차이가 날 수 있습니다. 추가 권한은 필요하지 않습니다.

새 효과 사용하기
• ‘비눗방울’을 고르면 투명한 방울이 천천히 흔들리며 내려옵니다.
  ‘창 위에 비눗방울 머무르기’를 켜면 창 가장자리에 약 10초 머문 뒤 사라집니다.
• ‘색종이’를 고르면 여섯 색의 작은 종잇조각이 회전하며 떨어집니다.
  창 위에 쌓인 조각은 약 45초 동안 남았다가 서서히 사라집니다.
• 두 효과 모두 내리는 양·바람·누적·전체 화면·작업 창 표시 옵션을 따릅니다.
  ‘쌓인 흔적 지우기’로 창에 남은 방울과 색종이를 지울 수 있습니다.
• 실제 날씨와 자동으로 연결하는 기능은 아직 없습니다. 이번에는 가능성만 검토했으며
  날씨 조회나 위치 권한 요청 없이 사용자가 직접 효과를 선택합니다.

기존 앱 업데이트하기
• 0.5.0 이상을 사용 중이면 앱의 ‘업데이트 확인…’으로 새 버전을 확인합니다.
• 0.4.0 이하는 업데이트 기능이 없으므로 DMG 또는 ZIP을 받아 직접 설치해 주세요.
• 같은 앱을 교체하여 설치하며 저장된 날씨 설정과 눈사람 위치는 유지합니다.
• 자동 업데이트 확인은 기본 ON이며 앱이 실행 중일 때 하루에 한 번 확인합니다.
  설정의 ‘자동 업데이트 확인’에서 끄실 수 있습니다. 다운로드와 설치는 직접 선택합니다.
• 업데이트 확인·다운로드에만 인터넷을 사용합니다. 배포는 GitHub의
  mindw96/WeatherWeather 저장소에서 제공합니다.

설정창 다시 열기
• Dock의 ‘쌓임쌓임’ 아이콘을 클릭하거나, 오른쪽 클릭 → ‘설정 열기…’를 선택합니다.
• 메뉴 막대의 날씨 아이콘 → ‘설정…’으로도 열 수 있습니다.
• 앱이 활성화된 상태에서는 ‘쌓임쌓임’ 메뉴 → ‘설정…’ 또는 ⌘,를 사용합니다.
• 설정창을 닫아도 효과는 계속됩니다. 끝내려면 ‘쌓임쌓임 종료’ 또는 ⌘Q를 사용합니다.
• 영문 환경에서는 앱 이름이 ‘Window Weather’로 표시됩니다.

표시 옵션과 눈사람
• ‘전체 화면에서도 쌓기’로 전체 화면의 누적 여부를 선택합니다.
• ‘사용 중인 창에도 효과 표시’를 끄면 작업 창 안의 효과와 그 창의 누적을 숨깁니다.
• ‘잠시 멈추기’는 눈사람을 포함한 효과를 숨기고, ‘쌓인 흔적 지우기’는 누적을 지웁니다.
• 눈 모드에서 눈사람의 모자·몸·팔을 잡아 같은 화면 안에서 끌어 옮기실 수 있습니다.
  놓은 위치는 화면별로 저장하며 다른 모니터로 넘겨 옮기는 기능은 제공하지 않습니다.
• ‘눈사람 표시’로 눈사람만 켜고 끕니다. 다른 효과에서는 눈사람이 숨겨집니다.

설정과 눈사람 위치는 Mac에 저장합니다. 창 제목·내용·화면 이미지·키보드 입력을
수집하거나 전송하지 않습니다. 일부 보조 패널은 실제 작업 창과 다르게 판단할 수 있습니다.
삭제하려면 앱을 종료하고 응용 프로그램 폴더의 앱을 휴지통으로 옮겨 주세요.
새로 작성한 앱 소스는 MIT 라이선스이며, 라이선스 고지는 앱 안에 포함합니다.
