# 쌓임쌓임 0.8.0

창과 바람에 반응하는 눈·잎, 반딧불과 별가루, 꾸밀 수 있는 눈사람을 추가했습니다. 앱마다 효과를 숨기고, 단축키나 로그인 자동 실행으로 더 편하게 사용할 수 있습니다. 원하는 도시의 실제 날씨에 맞춰 눈·비를 선택하는 기능도 제공합니다.

배포 상태: 버전 0.8.0 · 빌드 14의 자동 검사와 여덟 효과 미리보기 확인을 마쳤습니다. 현재 Mac 잠금으로 실제 데스크톱 통합 검사를 기다리고 있으며 통합 Release 빌드·서명을 진행 중입니다. 앱·DMG의 Apple 공증·Sparkle 업데이트 서명·공개 배포는 아직 완료되지 않았으며 0.8.0 다운로드를 제공하지 않습니다.

## 창과 계절의 움직임

- **바람 방향·세기 분리:** 왼쪽·오른쪽과 0~100% 세기를 따로 고릅니다. 기존 바람 설정도 유지합니다.
- **흩어지는 눈:** 창을 움직이면 가장자리의 눈이 조금 흩어지거나 작은 조각으로 떨어집니다.
- **다시 날리는 잎과 꽃잎:** 바람이 강하면 창 위에 쌓인 낙엽·벚꽃 일부가 다시 떠올랐다 내려앉습니다. 창·바람 반응은 설정에서 끌 수 있습니다.
- **빗물 파문과 방울:** 비가 닿은 자리에 작은 파문이 생기고, 가까운 물방울이 합쳐져 커지면 떨어집니다.
- **반딧불·별가루:** 여름의 작은 빛과 은은한 별을 더했습니다. 창 가장자리에 잠시 머물다가 사라집니다.
- **눈사람 꾸미기:** 모자·목도리를 각각 다섯 색 중에서 고르고 크기를 60~150%로 조절합니다. 드래그와 화면별 위치 저장을 유지합니다.

## 작업 중에도 편하게

- **효과를 숨길 앱:** 원하는 앱을 선택하면 해당 창 안과 창 위의 효과를 숨깁니다. 기존 작업 창 표시·모니터 선택 옵션과 함께 쓸 수 있습니다.
- **전역 단축키:** 다른 앱을 사용하는 중에도 선택한 키 조합으로 전체 효과를 숨기거나 복원합니다. 기본값은 꺼짐입니다.
- **30분 동안 숨기기:** 잠깐 쉬게 하고 시간이 지나면 자동으로 다시 내립니다.
- **Mac 로그인 시 자동 실행:** 설정에서 켜고 끌 수 있습니다. 자동 실행을 켤 때 설정창 없이 시작하도록 바꾸며, 시작 시 설정창 표시도 따로 선택할 수 있습니다.

## 실제 날씨 연동

기본값은 꺼짐입니다. 켠 뒤 도시를 검색·선택하면 약 15분마다 눈·비를 자동 반영합니다. 강수가 없을 때 표시할 기본 효과도 선택할 수 있습니다. 직접 효과를 고르면 30분 동안 유지하고, 원할 때 바로 자동 연동으로 돌아갈 수 있습니다.

날씨 연결이 끊기면 최근 유효값을 잠시 유지하고 기준 시각이 1시간을 넘으면 기본 효과를 표시합니다. 설정에서 날씨 기준 시각과 연결 상태를 확인할 수 있습니다.

기기의 현재 위치를 조회하지 않습니다. 도시 검색어와 선택한 도시의 좌표가 Open-Meteo에 전달됩니다. 계정이나 API 키 입력은 필요하지 않으며 수동 효과는 계속 오프라인에서 동작합니다. [날씨 연동과 개인정보 안내](../../WEATHER_INTEGRATION.md)

## 설치와 기존 설정

공개 배포 후 macOS 14 이상용 Apple Silicon·Intel 통합 DMG와 앱만 담은 ZIP을 제공할 예정입니다. 0.5.0 이상에서는 앱의 **업데이트 확인…**을 사용할 수 있습니다. 0.4.0 이하는 직접 설치가 필요합니다.

기존 모니터 선택·전체 화면·작업 창 표시·눈사람 위치 설정은 유지합니다. 설정창은 Dock 아이콘, 메뉴 막대의 **설정…**, 앱 활성 상태의 **⌘,**로 다시 열 수 있습니다.

프리셋·날씨 소리·모니터마다 다른 효과·Windows 버전은 이번 릴리스에 포함하지 않습니다. [사용 안내](START_HERE.ko.txt)와 [검증 상태](VALIDATION.md)를 제공합니다.
