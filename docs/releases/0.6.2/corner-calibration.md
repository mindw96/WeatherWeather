# 0.6.2 모서리 반경 보정

2026-11-06. 사용자가 제공한 186×158픽셀의 모서리 부분 이미지를 읽어, 기존 효과의 원호와 그 아래 회색 창 테두리를 비교했습니다. 원본 이미지는 저장소나 공개 배포 파일에 복사하지 않았습니다. 다른 앱의 화면을 새로 캡처하지 않았으며 제품 코드에서 이미지 분석을 수행하지 않습니다.

## 관측과 선택

푸른 물막과 겹치지 않아 구분 가능한 회색 테두리에서 아래 지점을 읽었습니다. 좌표 원점은 첨부 이미지의 왼쪽 위이며 단위는 픽셀입니다. 반투명 테두리와 안티앨리어싱이 있으므로 실제 외곽의 정확한 측정값으로 해석하지 않습니다.

```text
(x, y):
(84, 51), (78, 54), (74, 57), (71, 60), (69, 63),
(67, 66), (66, 69), (65, 72), (64, 75), (64, 78)
```

왼쪽 위 원호의 반경을 `r`, 창의 평평한 왼쪽 경계를 `x0`, 상단 경계를 `y0`로 놓고 다음 식의 예측 x와 관측 x 사이 평균제곱오차를 최소화했습니다.

```text
predictedX(y) = x0 + r - sqrt(r² - (y - y0 - r)²)
```

`r=24…36`, `x0=62.5…64.0`, `y0=48.0…50.0`을 각각 0.1픽셀 간격으로 탐색한 결과는 다음과 같습니다. 동일한 허용 범위에서 반경을 고정한 비교도 함께 수행했습니다.

| 반경 | 최적 왼쪽 경계 | 최적 상단 경계 | 가로 방향 RMS 오차 |
| --- | ---: | ---: | ---: |
| 30.5px, 세 변수 탐색 | 63.9px | 49.2px | 약 0.13px |
| 30px 고정 | 64.0px | 49.3px | 약 0.14px |
| 32px 고정 | 63.6px | 48.8px | 약 0.18px |
| 52px 고정 | 62.5px | 48.0px | 약 9.02px |

신호등 버튼의 이미지상 지름이 약 24픽셀인 점은 2배 배율 화면이라는 해석과 일치합니다. **2배 배율은 원본 디스플레이 메타데이터로 확인한 값이 아니라 이미지로부터의 추정**입니다. 이 해석에서 기존 26pt는 52px이며, 새 16pt는 32px입니다. 따라서 macOS 26 이상에서 사용하는 추정 반경을 **26pt에서 16pt로 줄이기로 했습니다.** 이전 macOS의 10pt 값과 화면 바닥·전체 화면 표면의 0 반경은 유지합니다.

이 표는 선택한 테두리 점에 원을 맞춘 결과이지, 해당 앱이 실제로 원형 곡선을 사용하거나 16pt 반경을 갖는다는 증명이 아닙니다. 첨부 화면을 개선하기 위해 별도의 초타원·창별 분류·화면 기록 권한은 추가하지 않습니다.

## 재현

아래 Python 코드는 외부 의존성과 원본 이미지 없이 위 관측점의 수치 적합을 재현합니다. 새로운 이미지를 분석하거나 변경하지 않습니다.

```python
import math

points = [(84, 51), (78, 54), (74, 57), (71, 60), (69, 63),
          (67, 66), (66, 69), (65, 72), (64, 75), (64, 78)]

def error(radius, x0, y0):
    cx, cy = x0 + radius, y0 + radius
    if any(abs(y - cy) > radius for x, y in points):
        return math.inf
    return sum((x - (cx - math.sqrt(max(0, radius**2 - (y - cy)**2))))**2
               for x, y in points) / len(points)

best = min((error(r / 10, x / 10, y / 10), r / 10, x / 10, y / 10)
           for r in range(240, 361)
           for x in range(625, 641)
           for y in range(480, 501))
print("RMS, radius, left, top:", math.sqrt(best[0]), *best[1:])
```

## 검증 범위

0.6.2의 일반 효과 미리보기와 설정창 미니 미리보기는 제품의 현재 추정 반경을 사용합니다. 모서리 전후 비교는 같은 16pt 가상 창 위에서 이전 26pt 효과와 현재 16pt 효과를 비교합니다. 기존 42개 곡선 렌더링 검사는 26pt의 일반 곡면 표본으로 유지하여 기본 반경 보정과 알고리즘 검증을 구분합니다.

실제 앱별 곡률을 반환하는 공개 API는 사용하지 않습니다. 독자적인 모양이나 다른 창 스타일에서는 오차가 남을 수 있으며, 이번 보정은 모든 창의 외곽에 정확히 일치한다는 보장이 아닙니다.
