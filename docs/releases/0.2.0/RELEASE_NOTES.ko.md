# Window Weather 0.2.0

2026년 11월 5일 공유용 버전입니다. macOS 14 이상에서 사용하는 메뉴 막대 앱이며, 계정이나 서버 연결 없이 실행합니다.

Apple Silicon(arm64)과 Intel(x86_64) 코드를 포함한 통합 Release 빌드이며, **Developer ID 서명과 Apple 공증을 완료했습니다.** Intel Mac 실기기 검증은 남아 있습니다.

## 들어 있는 기능

- **눈:** 눈송이가 내리고 창의 윗부분에 완만한 높낮이로 쌓입니다.
- **비:** 창 위에 닿은 빗방울이 튀고, 얕은 물막이 생겼다가 사라집니다.
- **가을 낙엽:** 주황·금색·붉은 잎이 회전하며 떨어지고, 여러 방향의 잎이 창 위에 남습니다.
- **봄 벚꽃:** 연분홍 꽃잎이 천천히 흔들리며 떨어지고, 창 위에 쌓였다가 서서히 사라집니다.
- **전체 화면 누적 선택:** ‘전체 화면에서도 쌓기’를 켜거나 끌 수 있습니다. 기본값은 꺼짐입니다.
- 내리는 양·바람·누적 여부 조절, 일시정지·재개, 쌓인 흔적 지우기, 두 화면 사이의 누적 상태 전달을 지원합니다.

## 사용하실 때 참고해 주세요

기존 Apple Silicon 개발 빌드에서 기본 동작을 점검했습니다. 이번 공유 패키지의 전체 화면 전환을 포함한 GUI 재검증은 제작 Mac의 화면 잠금으로 보류했으며, Intel Mac 실기기 확인도 남아 있습니다.

전체 화면 옵션은 화면을 가득 채운 최대화 창에도 적용됩니다. 옵션을 끄면 해당 창의 기존 누적도 지워지며, 낙하 효과는 유지됩니다.

창의 위치와 사각형 경계를 기준으로 동작합니다. 둥근 모서리나 비정형 창의 모습까지 정확히 따라가지는 않으며, 창 이동 반영에 짧은 지연이 있을 수 있습니다.

화면 구성 자체를 바꾸면 쌓인 흔적이 초기화됩니다. 일부 앱의 Spaces·Mission Control 조합, 잠자기 복귀와 여러 배율의 모니터 조합은 추가 확인 중입니다.

Windows 버전과 로그인 시 자동 실행은 아직 제공하지 않습니다. 처음 실행하는 방법은 함께 있는 `START_HERE.ko.txt`에 안내되어 있습니다.

## 개인정보와 라이선스

효과를 그리기 위해 창의 위치·크기 등 창 정보를 사용합니다. 창 제목이나 내용, 화면 이미지, 키보드 입력은 수집하지 않으며 외부로 전송하지 않습니다. 설정은 Mac에 저장합니다.

새로 작성한 앱 소스는 함께 제공되는 MIT 라이선스를 따릅니다. Koi의 코드·이미지·음원은 포함하지 않습니다.
