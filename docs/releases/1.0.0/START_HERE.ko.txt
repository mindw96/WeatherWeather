쌓임쌓임 1.0.0 — GitHub 직접 배포 사용 안내

눈·비·낙엽·벚꽃·비눗방울·색종이·반딧불·별가루가 창 위에 내려앉는 Mac 앱입니다.
회원가입·로그인 없이 사용하며 수동 효과는 인터넷 없이 동작합니다.
한국어 이름은 ‘쌓임쌓임’, 영문 이름은 ‘Window Weather’, 파일 이름은 WindowWeather.app입니다.

배포 상태: 1.0.0 · 빌드 15 직접 배포를 완료했습니다.
통합 앱·DMG의 Developer ID 서명·Apple 공증과 Sparkle 업데이트 서명을 완료했습니다.
최종 앱의 3개 모니터 GUI 검사 78개·설정 검사 24개·날씨 서비스 검사 12개를 통과했습니다.
GitHub 공개 다운로드·Sparkle 버전 판별·현재 Mac 설치와 실행을 확인했습니다.
다운로드: https://github.com/mindw96/WeatherWeather/releases/tag/v1.0.0

지원 환경
• macOS 14 이상, Apple Silicon·Intel 통합 앱을 제공합니다.
• 모든 macOS 버전·Intel 실기기·모니터 조합을 검증했다는 의미는 아닙니다.
• Windows 버전은 Mac 기능과 품질을 다듬은 뒤 진행합니다.

설치와 업데이트
1. 기존 앱을 종료합니다.
2. DMG를 열어 앱을 Applications로 끌어 옮깁니다.
   ZIP은 압축을 풀어 나온 앱 하나를 응용 프로그램 폴더로 옮깁니다.
3. 응용 프로그램 폴더에서 실행합니다. 설치 후 DMG는 꺼내셔도 됩니다.
4. 설정창에서 원하는 효과를 선택합니다.
• 0.5.0 이상 직접 배포판은 ‘업데이트 확인…’으로 새 버전을 확인할 수 있습니다.
• 자동 업데이트 확인은 하루 한 번이며 다운로드·설치는 직접 선택합니다.
• 앱을 교체해도 기존 설정과 화면별 눈사람 위치는 유지합니다.

효과와 바람
• 효과 선택 영역에서 여덟 효과 중 하나를 고릅니다.
• ‘내리는 양’은 입자 수를, ‘바람 방향’은 왼쪽·가운데(없음)·오른쪽을 조절합니다.
• ‘바람 세기’를 0~100%로 조절하며 0%이면 바람의 영향을 끕니다.
• ‘가운데(없음)’는 저장된 세기를 바꾸지 않고 바람만 멈춥니다.
  왼쪽이나 오른쪽을 다시 선택하면 저장된 세기로 돌아갑니다. 재실행 뒤에도 기억합니다.
• ‘창과 바람에 쌓인 효과가 반응’을 켜면 창을 움직일 때 눈 조각이 떨어지고,
  강한 바람에 쌓인 낙엽·벚꽃 일부가 다시 날립니다. 끄면 이 반응을 멈춥니다.
• 비가 창에 닿으면 파문이 생기고 가까운 물방울이 합쳐져 커지면 떨어집니다.
• 반딧불은 창 가장자리에 약 4초, 별가루는 약 8초 머문 뒤 사라집니다.
• ‘쌓인 흔적 지우기’로 창에 남은 누적을 지울 수 있습니다.

앱·모니터·전체 화면 표시
• ‘효과를 숨길 앱’에서 실행 중인 앱을 추가하거나 ‘앱 선택…’으로 고릅니다.
  선택한 앱의 창 안과 창 위의 누적을 숨기며, 목록에서 빼면 다시 표시합니다.
• ‘사용 중인 창에도 효과 표시’를 끄면 현재 작업 창도 숨깁니다.
  두 옵션은 독립적으로 적용합니다. 숨긴 상태에서도 누적의 시간은 흐릅니다.
• ‘효과를 표시할 모니터’에서 원하는 화면만 켭니다. 선택은 저장합니다.
  꺼진 모니터의 효과는 초기화되며 다시 켜면 새로 시작합니다.
• 모든 모니터를 꺼도 설정창과 미리보기는 사용할 수 있습니다.
• ‘전체 화면에서도 쌓기’는 전체 화면·최대화 창의 누적 여부를 정합니다.
  기본값은 꺼짐이며, 끄는 순간 해당 창의 누적을 지웁니다. 낙하 효과는 유지합니다.
• 일반 창 모서리는 OS 스타일에 맞춘 추정 곡선입니다. 독자적인 창 외곽은 다를 수 있습니다.

눈사람 꾸미기
• 눈 모드에서 ‘눈사람 표시’를 켭니다.
• 모자·목도리 색을 각각 고르고 크기를 60~150%로 바꿀 수 있습니다.
• 눈사람의 모자·몸·팔을 잡아 같은 모니터 안에서 옮깁니다. 놓은 위치는 저장합니다.
• 다른 효과나 일시정지 상태에서는 숨깁니다. 쌓인 흔적 지우기와는 독립적입니다.
• 효과를 숨긴 창과 겹치는 눈사람 부분은 보이거나 드래그 입력을 받지 않습니다.

빠른 제어와 자동 시작
• ‘어디서나 단축키로 숨기기·복원’을 켜고 ⌃⌥⌘P / ⌃⌥⌘Space / ⌃⌥⌘S 중 고릅니다.
  Control + Option + Command와 선택한 키를 함께 누릅니다. 다른 앱 사용 중에도 작동합니다.
  등록 오류가 표시되면 다른 조합을 선택합니다. 기본값은 꺼짐입니다.
• ‘30분 동안 숨기기’를 누르면 잠시 숨겼다가 자동으로 다시 표시합니다.
• ‘Mac 로그인 시 자동 실행’을 켜면 다음 로그인부터 실행합니다.
  켤 때 ‘시작할 때 설정창 열기’를 끄며 이 옵션은 이후 따로 바꿀 수 있습니다.
• 시스템 승인이 필요한 경우 설정의 버튼으로 macOS 로그인 항목 설정을 엽니다.

실제 날씨 연동 — 선택 기능
1. ‘실제 날씨에 맞춰 효과 바꾸기’를 켭니다. 기본값은 꺼짐입니다.
2. 도시 이름을 검색하고 국가·행정 구역을 확인해 선택합니다.
3. ‘비·눈이 없을 때’ 표시할 기본 효과를 고릅니다.
• 약 15분마다 선택 도시의 현재 날씨를 조회합니다. ‘지금 날씨 확인’으로 직접 갱신합니다.
• 직접 다른 효과를 고르면 30분 동안 유지합니다. ‘자동 연동 재개’로 바로 돌아갈 수 있습니다.
• 조회 실패 시 최근 유효값을 잠시 유지하고, 기준 시각이 1시간을 넘으면 기본 효과로 돌아갑니다.
• 날씨 기준 시각·연결 상태를 설정에서 확인할 수 있습니다.
• 기기의 현재 위치는 조회하지 않습니다. 도시 검색어와 선택한 도시의 좌표를
  Open-Meteo에 전송합니다. 현재 위치 권한·계정·API 키 입력은 필요하지 않습니다.
• 수동 효과는 인터넷 없이 사용할 수 있습니다. 날씨 연동·업데이트에는 인터넷이 필요합니다.
• 날씨 데이터: Open-Meteo, CC BY 4.0. 현재 값은 기상 모델 자료라 창밖과 차이가 날 수 있습니다.

설정창 다시 열기와 종료
• Dock 아이콘 클릭 또는 오른쪽 클릭 → ‘설정 열기…’를 사용합니다.
• 메뉴 막대의 날씨 아이콘 → ‘설정…’으로도 엽니다.
• 앱이 활성화된 상태에서는 ⌘,로 설정을, ⌘Q로 종료를 실행합니다.
• 설정창을 닫아도 효과는 계속됩니다. 설정이 길면 아래로 스크롤해 주세요.

개인정보와 범위
• 창 위치·크기·ID·레이어·소유 프로세스 정보를 화면 표현에 사용합니다.
  창 제목·내용·화면 이미지는 수집하거나 전송하지 않습니다.
• 앱별 제외 목록은 앱의 번들 ID·이름을 이 Mac에 저장하며 외부로 보내지 않습니다.
• 전역 단축키는 특정 조합만 등록합니다. 전체 키 입력을 감시하거나 기록하지 않습니다.
• 눈사람 클릭 판정에 포인터 위치를 메모리에서 사용하지만 이동 기록은 남기지 않습니다.
• 화면 기록·Accessibility·현재 위치 권한을 요청하지 않습니다.
• 일부 도구 패널은 실제 작업 창과 다르게 판단될 수 있습니다.
• 이번 버전에 프리셋·날씨 소리·모니터별 다른 효과는 포함하지 않습니다.
• 삭제하려면 앱을 종료하고 응용 프로그램 폴더의 앱을 휴지통으로 옮깁니다.
  로그인 자동 실행을 사용했다면 먼저 설정에서 끌 수 있습니다.
• 앱 소스는 MIT 라이선스이며 앱에 제3자 라이선스 고지를 포함합니다.
