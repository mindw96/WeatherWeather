# Window Weather 0.4.0

2026년 11월 5일 버전입니다. macOS 14 이상에서 계정이나 서버 연결 없이 실행하는 Apple Silicon(arm64)·Intel(x86_64) 통합 앱입니다. Intel Mac과 macOS 14 실기기 실행은 아직 확인하지 않았습니다.

배포 상태: Developer ID 서명과 Apple 공증을 완료했습니다.

## 개선: 설정창을 Dock에서도 열기

- 앱 실행 중 Dock에 Window Weather 아이콘을 표시합니다. 아이콘을 클릭하거나 오른쪽 클릭 → **‘설정 열기…’**로 설정창을 엽니다.
- 기존 메뉴 막대의 날씨 아이콘 → **‘설정…’**도 계속 제공합니다.
- Window Weather가 활성 앱일 때 상단 앱 메뉴 → **‘설정…’** 또는 **⌘,**로 설정창을 열 수 있습니다.
- 설정창을 닫거나 최소화한 뒤에도 다시 열 수 있습니다. 설정창을 닫아도 날씨 효과는 계속됩니다.
- 앱과 효과를 모두 종료하려면 메뉴 막대의 **‘종료’**, 앱 메뉴의 **‘Window Weather 종료’**, 또는 앱이 활성 상태일 때 **⌘Q**를 사용합니다.

공유 ZIP을 압축 해제한 뒤 폴더 안의 `WindowWeather.app`을 실행해 주세요. 계속 사용하실 경우 ‘응용 프로그램’ 폴더로 옮기셔도 됩니다. 기존 버전이 실행 중이면 먼저 종료해 주세요.

## 새 기능: 눈사람 표시와 위치 이동

- 눈 모드에서 각 화면의 오른쪽 아래에 눈사람을 표시합니다. **‘눈사람 표시’**는 기본 ON이며, 선택한 값은 Mac에 저장합니다.
- 스위치를 끄거나 다른 날씨 모드로 전환하면 눈사람을 숨깁니다. 눈 모드로 돌아오면 저장된 선택을 따릅니다.
- 눈사람의 모자·몸·팔을 마우스로 잡아 같은 화면 안에서 옮길 수 있습니다. 눈사람 전체가 화면 밖으로 나가지 않도록 제한합니다.
- 드래그를 놓으면 화면별 상대 위치를 저장합니다. 화면 크기가 바뀌어도 그 화면 안의 상대 위치를 복원하며, 저장된 위치가 없을 때 오른쪽 아래에서 시작합니다.
- ‘쌓인 흔적 지우기’는 눈사람 표시나 저장 위치와 독립적으로 동작합니다.
- ‘사용 중인 창에도 효과 표시’가 OFF이면 작업 창과 겹치는 부분은 가려집니다. 가려진 부분으로 드래그를 시작할 수 없습니다.
- 설정 미리보기에는 표시 여부를 반영합니다. 드래그 이동은 실제 데스크톱의 눈사람에서 사용할 수 있습니다.

눈사람은 새로 그린 벡터 도형이며 외부 이미지 파일을 사용하지 않습니다. 기존 눈·비·낙엽·벚꽃, 전체 화면 누적 선택, 작업 창 효과 표시 선택, 강도·바람 조절, 일시정지와 누적 지우기를 함께 제공합니다.

## 현재 범위

눈사람은 각 화면 안에서 이동하며 다른 모니터로 넘겨 옮기는 기능은 제공하지 않습니다. 작업 창은 활성 앱의 맨 앞 일반 창을 기준으로 판단하므로 일부 보조 패널·특수 창에서는 실제 포커스와 다를 수 있습니다.

실제 마우스 드래그, 여러 배율의 화면 구성, Spaces·Mission Control·잠자기 복귀, Intel Mac과 macOS 14 실기기 동작은 실행 환경에 따른 확인이 필요합니다. 이 문서는 해당 검증을 완료했다는 의미가 아닙니다. Windows 버전은 아직 제공하지 않습니다.

## 개인정보와 라이선스

설정과 화면별 눈사람 위치는 Mac에 저장합니다. 창의 위치·크기와 소유 프로세스 ID를 효과 배치에 사용하며, 창 제목이나 내용·화면 이미지·키보드 입력은 수집하거나 외부로 전송하지 않습니다.

새로 작성한 코드와 벡터 도형은 MIT 라이선스를 따릅니다. Koi의 코드·이미지·음원은 포함하지 않습니다.
