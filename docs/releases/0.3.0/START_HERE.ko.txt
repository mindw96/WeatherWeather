Window Weather 0.3.0 — 처음 사용하시는 분께

창 위에 눈, 비, 가을 낙엽, 봄 벚꽃을 내리는 작은 Mac 앱입니다.
회원가입·로그인·인터넷 연결 없이 사용하실 수 있습니다.

지원 환경
• macOS 14 이상
• Apple Silicon 및 Intel Mac용 통합 앱
• Windows용 앱은 아직 제공하지 않습니다.

이 파일의 배포 상태
개발자 서명(Developer ID)과 Apple 공증을 완료한 공유용 통합 빌드입니다.
Intel Mac 실기기에서의 실행은 아직 확인하지 않았으며, 자세한 검증 범위는
RELEASE_NOTES.ko.md에 정리되어 있습니다.

설치와 실행
1. 전달받은 ZIP 파일을 더블 클릭하여 압축을 풀어 주세요.
2. WindowWeather.app을 ‘응용 프로그램’ 폴더로 옮겨 주세요.
   이전 버전이 실행 중이면 메뉴 막대에서 먼저 ‘종료’를 선택해 주세요.
3. 옮긴 앱을 더블 클릭하면 설정창과 메뉴 막대의 날씨 아이콘이 나타납니다.
   별도 설치 프로그램이나 터미널 명령은 필요하지 않습니다.

처음 실행할 때
처음 열 때 인터넷에서 다운로드한 앱인지 확인하는 창이 표시되면,
앱 이름과 전달받은 파일을 확인한 뒤 ‘열기’를 선택해 주세요.

앱이 차단되거나 손상되었다는 경고가 나오면 최신 배포 파일인지 확인해 주세요.
같은 문제가 계속되면 파일을 보내 주신 분께 경고 내용을 알려 주세요.
회사·학교에서 관리하는 Mac은 별도 설치 정책이 적용될 수 있습니다.
Apple 공식 안내: https://support.apple.com/ko-kr/102445

이번 버전의 새 옵션
설정의 ‘사용 중인 창에도 효과 표시’는 기본적으로 켜져 있습니다.
• 켜짐: 기존처럼 작업 중인 창에도 눈·비·낙엽·벚꽃이 보입니다.
• 꺼짐: 작업 중인 창 안으로 지나가는 효과와 그 창 위에 쌓인 효과를 숨깁니다.
  다른 창과 바탕화면의 효과는 계속됩니다.
• 이 옵션은 쌓인 흔적을 지우지 않습니다. 다른 창으로 포커스를 옮기거나
  옵션을 다시 켜면 남아 있는 효과가 다시 보입니다.
• ‘전체 화면에서도 쌓기’와 별도 옵션입니다. 전체 화면에 쌓기를 켰더라도
  사용 중인 창의 효과 표시를 끄면 해당 창에서는 효과가 보이지 않습니다.

사용 중인 창은 현재 사용 중인 앱의 맨 앞 일반 창을 기준으로 찾습니다.
별도 손쉬운 사용 권한은 요청하지 않습니다. 일부 보조 패널이나 특수한 창은
실제 입력을 받는 창과 다르게 판단할 수 있습니다.

기본 사용 방법
• 설정창이나 메뉴 막대에서 눈 / 비 / 낙엽 / 벚꽃을 선택합니다.
• 내리는 양과 바람을 조절하고, 창 위에 쌓일지 선택하실 수 있습니다.
• ‘전체 화면에서도 쌓기’는 기본적으로 꺼져 있습니다. 켜면 전체 화면과
  화면을 가득 채운 최대화 창에도 쌓입니다. 이 옵션은 낙하 자체를 끄지 않습니다.
• ‘쌓인 흔적 지우기’로 쌓인 눈·물·잎·꽃잎을 지울 수 있습니다.
• ‘잠시 멈추기’로 효과를 숨기고, ‘다시 내리기’로 재개합니다.
• 설정창을 닫아도 효과는 계속됩니다. 다시 열려면 메뉴 막대의 날씨 아이콘에서
  ‘설정…’을 선택해 주세요.
• 앱을 끝내려면 메뉴 막대의 날씨 아이콘에서 ‘종료’를 선택합니다.

삭제하기
메뉴 막대에서 앱을 종료한 뒤 ‘응용 프로그램’의 WindowWeather.app을
휴지통으로 옮겨 주세요.
