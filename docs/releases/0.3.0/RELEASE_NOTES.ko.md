# Window Weather 0.3.0

2026년 11월 5일 버전입니다. macOS 14 이상에서 사용하는 메뉴 막대 앱이며, 계정이나 서버 연결 없이 실행합니다. Apple Silicon(arm64)과 Intel(x86_64)을 지원하는 통합 빌드입니다.

**Developer ID 서명과 Apple 공증을 완료했습니다.** Intel Mac 실기기 검증은 남아 있습니다.

## 새 기능: 작업 중인 창의 효과 표시 선택

설정에 **‘사용 중인 창에도 효과 표시’** 옵션을 추가했습니다. 기존 동작을 유지하도록 기본값은 **켜짐**이며, 선택은 Mac에 저장됩니다.

- **켜짐:** 작업 중인 창에도 눈·비·낙엽·벚꽃을 표시합니다.
- **꺼짐:** 작업 중인 창 안을 지나는 효과와 그 창 위에 쌓인 효과 전체를 숨깁니다. 다른 창의 효과는 유지합니다.
- 숨길 때 쌓인 흔적을 지우지 않습니다. 다른 창으로 포커스를 옮기거나 옵션을 다시 켜면 남아 있는 효과가 다시 보입니다.
- 전체 누적 여부와 **‘전체 화면에서도 쌓기’** 설정과 독립적으로 선택합니다. 전체 화면 누적을 켰더라도, 현재 사용 중인 창의 효과 표시를 끄면 그 창의 효과는 보이지 않습니다.

현재 사용 중인 앱의 맨 앞 일반 창을 기준으로 대상을 찾습니다. 추가 손쉬운 사용 권한 없이 동작하며, 일부 떠 있는 보조 패널이나 특수한 창에서는 실제 입력을 받는 창과 다르게 판단할 수 있습니다.

## 함께 제공하는 기능

- 눈송이와 창 위 적설
- 빗줄기, 충돌 물방울, 얕은 물막
- 회전하며 떨어지고 쌓이는 가을 낙엽과 봄 벚꽃
- 내리는 양·바람·누적 여부 조절, 전체 화면 누적 선택
- 일시정지·재개, 쌓인 흔적 지우기, 화면 사이의 누적 상태 전달

## 사용하실 때 참고해 주세요

핵심 로직 테스트 52개와 네 효과의 숨김·복원 및 설정 저장 검사 42개를 통과했습니다. 공유용 Release 앱에서도 42개 검사를 통과했습니다. 현재 제작 Mac 화면이 잠겨 있어 실제 창을 전환하는 GUI 검사는 보류했습니다.

창의 위치와 사각형 경계를 기준으로 동작합니다. 둥근 모서리나 비정형 창의 모습까지 정확히 따라가지는 않으며, 포커스 변경이나 창 이동 반영에 짧은 지연이 있을 수 있습니다.

전체 화면 누적 옵션은 화면을 가득 채운 최대화 창에도 적용됩니다. 이 누적 옵션을 끄면 해당 창의 기존 누적은 지워집니다. 새로 추가한 효과 표시 옵션은 누적을 삭제하지 않고 숨긴다는 점에서 동작이 다릅니다.

화면 구성 자체를 바꾸면 쌓인 흔적이 초기화됩니다. 일부 앱의 Spaces·Mission Control 조합, 잠자기 복귀와 여러 배율의 모니터 조합은 추가 확인이 필요합니다. Intel Mac 실기기에서의 실행은 아직 확인하지 않았습니다.

Windows 버전과 로그인 시 자동 실행은 아직 제공하지 않습니다. 처음 실행하는 방법은 함께 있는 `START_HERE.ko.txt`에 안내되어 있습니다.

## 개인정보와 라이선스

효과를 그리기 위해 창의 위치·크기와 창을 소유한 앱의 프로세스 ID를 Mac 안에서만 사용합니다. 창 제목이나 내용, 화면 이미지, 키보드 입력은 수집하지 않으며 외부로 전송하지 않습니다. 설정은 Mac에 저장합니다.

새로 작성한 앱 소스는 함께 제공되는 MIT 라이선스를 따릅니다. Koi의 코드·이미지·음원은 포함하지 않습니다.
