# 실제 날씨 연동

갱신일: **2026-11-11 (Asia/Seoul)**. 이번 Mac 개발 버전에 **선택한 도시의 현재 날씨에 따라 효과를 바꾸는 기능**을 구현했습니다. 기본값은 꺼짐이며 수동 효과는 계속 오프라인에서 작동합니다. 배포 완료 여부는 해당 버전의 릴리스 검증 기록을 따릅니다.

## 사용 방법과 동작

1. 설정의 **실제 날씨에 맞춰 효과 바꾸기**를 켭니다.
2. 도시 이름을 입력하고 **검색**을 누른 뒤 국가·행정 구역을 확인해 도시를 선택합니다. 한국어 검색 결과가 없으면 영문 이름도 사용할 수 있습니다.
3. **비·눈이 없을 때** 표시할 기본 효과를 선택합니다.
4. 선택한 도시에 눈이 오면 눈, 비가 오면 비를 자동 적용합니다. **지금 날씨 확인**으로 직접 갱신할 수 있습니다.

앱 실행 중 자동 조회 간격은 15분입니다. 잠자기 복귀 시에도 갱신 필요 여부를 확인하며, 최근 15분 안에 요청했다면 중복 요청하지 않습니다. 애니메이션과 분리된 비동기 요청을 사용합니다.

직접 효과를 고르면 **30분 동안 수동 선택을 유지**하고 자동으로 연동을 재개합니다. 설정의 **자동 연동 재개**로 즉시 돌아갈 수도 있습니다. 자동 선택은 사용자가 정한 기본 효과·강도·바람·눈사람 설정을 덮어쓰지 않습니다.

## 날씨 판정과 오래된 값 처리

현재 응답의 `weather_code`, `rain`, `showers`, `snowfall`을 사용합니다. 하루 대표 예보나 강수 확률로 지금 비가 온다고 추정하지 않습니다.

| 현재 정보 | 효과 |
| --- | --- |
| 눈 코드 `71, 73, 75, 77, 85, 86` 또는 양수 강설량 | 눈 |
| 비·이슬비·어는 비·소나기 코드 `51, 53, 55, 56, 57, 61, 63, 65, 66, 67, 80, 81, 82`, 또는 양수 비·소나기량 | 비 |
| 눈과 비가 함께 있음 | 눈 우선 |
| 맑음·구름·안개 | 선택한 기본 효과 |
| 뇌우 `95, 96, 97, 99` | 실제 강수량에 따라 눈·비, 강수량이 없으면 기본 효과 |
| 실패·알 수 없는 코드·유효하지 않은 수치 | 최근 유효값이 있으면 잠시 유지, 없으면 기본 효과 |

어는 비를 기온만으로 눈으로 바꾸지 않습니다. 응답 좌표·숫자·시각을 검증하고, 관측 기준 시각이 **1시간을 넘으면 기본 효과**로 돌아갑니다. 현재보다 15분을 초과해 미래인 응답도 사용하지 않습니다. 날씨 기준 시각과 연결 지연·기본 효과 사용 상태를 설정에 표시합니다.

도시 변경이나 자동 연동 해제 시 진행 중인 요청을 취소하고, 늦게 도착한 이전 응답이 효과를 바꾸지 못하게 합니다. 자동 연동을 끄면 현재 표시 중인 효과를 수동 모드로 유지합니다. 날씨 응답은 메모리에만 보관하며 재실행하면 다시 조회합니다.

Open-Meteo의 현재 값은 15분 단위 기상 모델 자료를 기반으로 하므로 창밖의 실황과 완전히 일치하거나 즉시 반영된다고 보장하지 않습니다. [현재 날씨·변수·WMO 코드 공식 문서](https://open-meteo.com/en/docs)

## 공급자와 배포 방식

회원가입이나 API 키 입력 없이 이용할 수 있는 **Open-Meteo**를 사용합니다. 도시 검색은 별도 지오코딩 API를 사용하며 검색 버튼을 누를 때 요청합니다. 도시를 자동으로 추측하거나 Apple 기본 날씨 앱의 저장 데이터를 읽지 않습니다. [지오코딩 공식 문서](https://open-meteo.com/en/docs/geocoding-api)

무료 API는 비상업 용도이고 호출 한도가 있으며 가동 시간 보장은 없습니다. 광고·구독 등 상업 모델을 추가하거나 사용량이 늘면 해당 조건을 다시 검토해야 합니다. 오픈소스 배포 자체가 상업적 이용까지 무료로 허용한다는 의미는 아닙니다. [이용 약관·개인정보 안내](https://open-meteo.com/en/terms)

설정 화면에 **Open-Meteo · 효과로 변환 · CC BY 4.0** 및 링크를 표시합니다. 앱 소스의 MIT 라이선스와 날씨 데이터의 출처 표시 조건은 별개입니다. [데이터 라이선스](https://open-meteo.com/en/licence)

Apple WeatherKit은 이번 구현에 사용하지 않습니다. macOS Developer ID 배포 지원과 REST 토큰 보관 방식은 별도 검토가 필요하며, WeatherKit 인증 키·entitlement·서버를 추가하지 않았습니다. [Apple WeatherKit](https://developer.apple.com/weatherkit/)

## 위치와 개인정보

- 현재 위치 권한을 요청하거나 기기의 현재 위치를 조회하지 않습니다.
- 자동 연동을 켠 뒤 도시를 검색하면 **검색어**를 지오코딩 서비스에 전송합니다.
- 날씨 조회에는 **선택 도시의 좌표**와 일반적인 HTTPS 요청 정보가 공급자에게 전달됩니다.
- 선택한 도시와 자동 연동 여부·기본 효과는 이 Mac의 설정에 저장합니다. 창 제목·내용·포인터 정보는 날씨 요청에 포함하지 않습니다.
- 자동 연동이 꺼져 있거나 검증 실행인 경우 서비스에서 날씨·도시 검색 요청을 보내지 않습니다.

## 검증

- `LiveWeatherPolicyTests`: 눈·비·어는 비·건조한 뇌우 매핑, 혼합 강수, 30분 수동 우선, 1시간 만료, 잘못된 코드·수치·좌표·미래 시각, 도시 저장과 검증을 다룹니다.
- `LiveWeatherValidation`: 세션 전용 `URLProtocol` 모의 응답으로 OFF 무요청, 검증 실행 무요청, 조회 간격, 수동 우선, 오래된 값 대체, 도시 변경·해제 후 늦은 응답 차단, 검색, HTTP 오류를 검사합니다. 실제 서비스에 요청하지 않습니다.
- 공개 샘플 도시 **서울**의 도시 검색·현재 날씨 API가 HTTP 200을 반환하고 실제 Swift 디코더로 처리되는지 별도로 확인했습니다. 기기 위치는 사용하지 않았습니다. [실 API 점검 요약](validation/weather-live.json)

도시·날씨 API의 장기 가용성, 지역별 체감 정확도와 장시간 전력 사용량은 별도 실사용 검증 대상입니다.
